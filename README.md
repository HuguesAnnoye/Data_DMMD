## Organisation

- `Table_2/`: 3 files corresponding to Table 2.
- `Table_3/`: 3 files corresponding to Table 3.
- `Table_5/data_1/` to `Table_5/data_10/`: 3 files per repetition, for a total of 30 files corresponding to Tables 4 and 5.

## File roles

- `orginal.fst`: reference population, 50,000 rows, covariates only.
- `orginal_pop.fst`: population, 50,000 rows, covariates and columns `w` and `p`.
- `orginal_samp.fst`: sample, 500 rows, covariates and columns `w` and `p`.

Tables 2, 4 and 5 use 14 covariates; Table 3 uses 5.
